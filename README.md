# Learning Center – November 2026

Lernabenteuer für die 3. Klasse: Mathematik, Deutsch, einfaches Englisch und Länderflaggen. Das Spiel bietet einen adaptiven Lernmix mit 20 Aufgaben, gezielte Fehlerwiederholungen, Sterne und Memory.

## Auf dem iPad starten

Nach Aktivierung von GitHub Pages: https://allessuper.github.io/Learning_Center_Nov2026/

**Einmalige Veröffentlichung:** Unter **Settings → Pages** bei **Build and deployment** „Deploy from a branch“, Branch **main**, Ordner **/(root)** wählen und speichern.

Die vollständige Web-App liegt in `docs/`. Die Originaldateien von Version 4.0 befinden sich unverändert in `Lernabenteuer_iPad_Startpaket_v4.zip` (42 Originaldateien mit ihren ursprünglichen Dateinamen).

## Datenschutz

Keine Anmeldung, keine Werbung, kein NVIDIA-API-Key und kein externes KI-Modell in dieser Version. Fortschritt und Fehlerkartei werden lokal im jeweiligen Browser gespeichert, nicht automatisch zwischen Geräten synchronisiert. GitHub Pages ist öffentlich; keine Kinder- oder Zugangsdaten in das Repository stellen.

## Testhinweis

Automatisierte Prüfungen und Chromium-Tests wurden im Projekt durchgeführt. Ein Praxistest auf einem echten iPad bleibt erforderlich.

## Version 8.0 – Lernniveau 3. Klasse

Die bisherigen Spielstände und die 20er-Lernmix-Logik bleiben erhalten. Mathe enthält Aufgaben im Zahlenraum bis 1.000 sowie Einmaleins und Teilen (bis 11 × 10); Deutsch enthält längere Lesetexte, Wortarten, Zeitformen und Rechtschreibung; Englisch ergänzt Schulsachen, Familie und sehr kurze Alltagsdialoge. Die Aufgabeauswahl wächst automatisch mit dem Lernstand. Flaggen, Zeit-Bank, Rücksprünge, Haustier, Boss und Schatzkarten bleiben bestehen. Die Kinder-App sendet keine Lerndaten an einen KI-Dienst.
